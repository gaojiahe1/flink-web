# ADR-003 平台元数据与运行存储的安全边界

更新：2026-10-12。状态：已采用。来源：最新明确要求、功能/部署文档及对应模块的现有实现。本记录为事后整理，不冒充完整历史讨论或原始选型过程。

- 背景/问题：平台元数据、制品和Flink状态职责不同；换存储或改主密钥可能无法恢复已有数据。
- 决策：元数据SQLite单实例/PVC或MySQL，迁移V1–V5保留；S3存制品及状态，不存元数据库。角色+ACL与Session/CSRF保护操作，密钥静态加密且主密钥稳定，预览/发布各脱敏。
- 原因：延续现有单实例与兼容约束，提供商/插件要按三条真实路径独立验收。
- 重要备选：自动切库搬迁、共享数据等同租户隔离、直接轮换主密钥而不重加密、以MinIO代替厂商认证均不采用。
- 影响范围：数据库、安全、配置、S3、下载器、Flink运行路径。
- 替代关系：2026-10-10加密配置部署为env.value且不新建Secret；显式已有Secret仍保留。旧自动生成Secret策略不再作为当前方案。
