# ADR-002 资源身份与保存点停止

更新：2026-10-12。状态：已采用。来源：最新明确要求、功能/部署文档及对应模块的现有实现。本记录为事后整理，不冒充完整历史讨论或原始选型过程。

- 背景/问题：同名资源重建、旧保存点与终态Checkpoint会导致错误删除或恢复。
- 决策：平台UUID、自增编号、集群UID/resourceVersion分别保留。持久化停止意图及实际配置，核对代数和UPGRADE Savepoint完成证据，先存恢复路径再删除；立即删除为独立显式策略。
- 原因：从当前实现/测试可核实其防误删和可续接效果；不是未经确认推断原始需求。
- 重要备选：只按名称删除、把ACCEPTED当完成、只见upgradeSavepointPath就删除、last-state停止均不采用。
- 影响范围：StopService、Operation/Query、纳管、恢复与草稿删除。
- 替代关系：旧共享停止/last-state方案已由当前Savepoint/立即删除规则替代。
