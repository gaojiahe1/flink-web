# ADR-005 轻量索引与增量记忆

更新：2026-10-12。状态：已采用。来源：最新明确要求、功能/部署文档及对应模块的现有实现。本记录为事后整理，不冒充完整历史讨论或原始选型过程。

- 背景/问题：跨聊天重复全量扫描成本高，旧文件和旧推断容易污染上下文。
- 决策：AGENTS→INDEX→相关REQ/模块/ADR→当前代码/测试；复用features/deployment；状态与短任务摘要分开，轻量Python标准库检查路径/锚点/检索。
- 原因：本次项目规模可用仓库Markdown与代码搜索实现，知识与源码版本关联、可审查回滚。
- 重要备选：向量数据库、复杂RAG、独立记忆服务、整段聊天缓存、每任务全量重建不采用。
- 影响范围：后续所有项目任务；首次治理允许有目的的广扫描，日常默认局部读取。
- 替代关系：本轮用户明确采用；不替代代码验证、用户决策或真实环境测试。

按业务查 [总索引](../INDEX.md) 定位关联需求/代码；参数与完整验收边界不重复抄写。
