# ADR-004 用户账号与三层 PodTemplate

更新：2026-10-12。状态：已采用。来源：最新明确要求、功能/部署文档及对应模块的现有实现。本记录为事后整理，不冒充完整历史讨论或原始选型过程。

- 背景/问题：共享与JM/TM角色配置强制合并会丢失用户表达，后端固定账号不满足最新要求。
- 决策：ServiceAccount由表单默认namespace-flink且允许修改，后端只校验。三层模板独立保存并交Operator合并；平台托管下载器/插件与角色模板共用时启用具名数组合并，关闭或挂载冲突报错。
- 原因：遵循2026-10-12明确用户要求，保留角色差异及用户已有账号。
- 重要备选：2026-10-01共享模板唯一/强制合并要求已被最新要求替代；不静默删角色模板、不猜RBAC。
- 影响范围：JAR/SQL/Session表单、Form/Yaml服务、PodTemplates、托管制品/插件渲染。
- 替代关系：当前有效；取代旧强制合并规则，不改变既有运行资源。
