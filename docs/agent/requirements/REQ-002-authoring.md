# REQ-002 JAR/YAML、ServiceAccount 与三层模板

更新：2026-10-20。状态：已实现；本地验证范围见 [验收记录](../validation.md)，不代表真实环境/全部版本验收。

背景：用户要求配置表单能表达已有模板和不同角色Pod配置，并允许用户填写运行账号。

需求范围：JAR、SQL、Session共用账号/模板编辑组件。 当前完整细则复用 [功能说明](../../features.md)，配置与环境操作见 [部署指南](../../deployment.md)。

## 验收标准

- 2026-10-20：JAR草稿列表置于编辑器左侧，支持搜索/折叠及响应式；切换保护真实修改，加载时新建不被旧请求阻塞或迟到回填。

- 默认填写{namespace}-flink，已有显式账号保留；后端不替换，不给既有无账号YAML补值。
- 共享/JM/TM模板自动识别、独立YAML编辑、默认折叠；清空只移除该处，无效或非对象拒绝提交。
- 托管文件与角色覆盖冲突明确拒绝；数组按名合并规则不被关闭，表单转换有明确确认。

关联：[模块](../modules/job-authoring.md)、[ADR](../decisions/ADR-004-templates.md)。关键代码及测试由模块链接定位，不维护第二份路径清单。

重要变更：10-04 编辑来源与转换确认；10-09 移除Metaspace独立字段；10-12可编辑账号/三层模板替代强制共享合并。

来源与确认：功能文档明确用户规则＋当前实现/测试交叉核对；五个可访问旧聊天的近期摘要仅作补充线索。原始全部历史讨论未完整读取。

后续修改更新本记录和相关模块；新验收注明真实环境、版本与未验证范围，不把历史报告当作本轮结果。

2026-10-12 补充验收：旧作业在编辑者保存新账号后，显式部署及停止后启动均使用新账号；仅运维权限仍复用实际运行账号。未保存表单不能生效。

补充适用范围：ServiceAccount 例外同时覆盖旧资源仍存在的直接启动/恢复和资源删除后的重建；平台编辑角色与作业编辑权限同时满足才采用草稿账号。最终176项后端回归和实际镜像闭环通过。

## 早期表单与界面要求（2026-10-13 补录）

2026-09-23～09-28 用户明确：沿用已有产品，参考阿里云/StreamPark 优化；Flink 配置采用支持常用 key 提示的文本域，镜像选择同步 YAML 的镜像和 Flink 版本，收起显示 Flink 版本、展开显示 tag，不提供镜像 digest 产品字段；SQL PodTemplate 可从模板获取。JM/TM 内存同行、CPU 同行，统一输入框/下拉框高度，字体与表单紧凑；SQL 草稿栏缩窄、独立滚动，长说明改为悬停/聚焦提示。后续三处模板与面板缩放规则仍以上文为准。

设计附件中的多集群、自动刷新、告警和监控菜单属于示例，不能覆盖用户的单 namespace、按需查询约束。制品校验 SHA-256、镜像发布时核对仓库摘要不属于被删除的镜像 digest 表单能力。原始需求附件存在版本缺口，见 [归档核对](../validation.md#初始平台聊天归档前核对2026-10-13)。

## 本聊天表单来源与覆盖保护（2026-10-13 补录）

- 09-29～09-30：全站表单错误在对应字段红框和就地说明，确认操作使用站内对话框；保存并部署受理后返回作业列表。JAR 文件刷新/上传按钮集中排布，文件选择区改为限高、可搜索的内嵌目录列表，避免目录过多撑长页面；数字与单位分离，与内存输入一致。镜像登记删除“显示名称、手填 Flink 版本、imagePullSecret”输入，Flink 版本由镜像 tag 识别；展示派生版本不等于恢复手填字段。
- 状态存储显式启用，默认 S3；Checkpoint/Savepoint/HA 路径和连接项自动进入同一份 Flink 配置，不要求用户填写路径、后端实现、S3 region 或 endpoint。保留 Checkpoint 间隔、数量、外部存储保留策略及恢复策略；选择恢复策略显示说明和对应参数。关闭清理托管 S3/HA 参数，已有 YAML 不因纳管自动重写。
- 10-04 最初要求未标记旧作业只能 YAML 编辑；同日后续用户明确允许复制时选择 JAR、编辑时确认可能改写 YAML 后尝试转换，故“永远禁用 JAR 表单”的旧结论已失效。editor=jar-v1 与 allowFormRewrite 区分已确认转换；解析失败留在 YAML，不静默覆盖。仅改标签不能替代保存/渲染入口的转换确认。
- 10-01 用户曾要求只生成共享 PodTemplate；现行三处独立编辑以 10-12 后续要求和 [ADR-004](../decisions/ADR-004-templates.md) 为准。10-04 曾新增 Metaspace 独立输入，10-09 已移除；既有值在 Flink 配置中保留，不把历史界面截图当当前字段。

本次仅核对代码与测试定义，没有重跑表单回归；历史各阶段结果见 [本次归档核对](../validation.md#作业与前端修复聊天归档核对2026-10-13)。

## SQL/Session 开发聊天来源补核（2026-10-13）

10-09 用户明确将新建 JAR 移到左侧“JAR 开发”：已有运行作业仅在作业管理出现，首次点击编辑才建立开发映射，不能批量把历史作业加入开发列表。作业列表区分 SQL/JAR，SQL 编辑跳到关联 SQL 草稿。后续同日要求 Session 新建/配置页参考作业编辑页，采用统一分区卡片和响应式字段网格；移除 JM/TM Metaspace 独立输入，而非删除已有 Flink 配置。

同日明确 JAR、SQL 草稿支持删除。当前入口复用修订、权限、关联与集群资源保护：JAR 删除同步作业记录并清专属目录；SQL 有有效部署关联时须先删除关联平台作业。取消/失败保留内容，删除其他 SQL 草稿不覆盖正在编辑的草稿。历史 30 项页面/19 项后端定向检查及后续镜像发布见 [本聊天核对](../validation.md#sql-与-session-开发聊天归档核对2026-10-13)，本轮仅静态核实。
