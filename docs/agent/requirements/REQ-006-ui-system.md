# REQ-006 全站界面与统一设计规范

更新：2026-10-29。状态：已实现；验收范围以 [记录](../validation.md) 为准。

用户要求：重新设计全部页面，解决格式、宽度、表单密度、字体与留白不一致；保留已验证的业务功能。

## 验收标准

- 2026-10-29：暖白/墨蓝取消灰黄叠色，工作面白底、蓝灰浅背景、深墨蓝文字与更清晰边框/强调色，正文/辅助文字保持可辨识对比；主题尺寸、MiSans及其余主题保持。用户后续要求Tab圆滑并否定硬分块图标栏：SQL辅助栏改为56px轨道、12px圆角独立竖签与8px间距，用细边界/柔和填充区分；AI/UDF整词横排在中文上方，Catalog整词侧排，不拆字母，不使用图标格/硬切线。短屏独立滚动，手机改横排圆角标签。

- 全部有效导航页面及登录共用紧凑布局，不引入第二套组件库。2026-10-28 用户选定默认「雾灰 / 青绿」、可切换「深色开发工作台」，另增加「暖白 / 墨蓝」浅色风格，替代此前固定蓝色要求；三套主题共用尺寸与业务布局。
- 顶栏与登录页提供主题选择，刷新及跨标签页保留/同步，持久化受限时仍可在当前页面使用；首次绘制按已保存主题初始化，未保存或无效值默认雾灰。
- SQL、YAML、Flink 配置、日志、语法高亮、差异、提示、确认框与诊断弹窗都随主题更新；切换不重建文档、不保存草稿、不改变选区、撤销记录和滚动位置。运行/警告/失败颜色独立于主题强调色。
- 同日用户确认全站界面采用MiSans：使用官方原版Web字体离线打包并保留许可/版权及软件内注明；代码使用独立等宽字体。页面标题18、区域标题16、表单分组14、正文13、说明12、注释11px；说明不得大于对应标题，同层级通过共享变量统一。
- SQL历史比较标题与代码两列共享边界，考虑原生滚动条占位；短内容两侧填满同一高度，长内容仍可滚动到末尾，保留差异高亮、查看和恢复原有边界。
- 主内容宽度随统一外框伸缩。页标题18px、正文13px、辅助12px；普通单行控件30px、普通双行记录基准56px、表头34px。代码正文、多行输入、图标按钮和长内容允许按用途设置尺寸，不能为凑行高裁掉操作或错误。
- 页头、卡片、筛选和分页遵循统一间距；表单用栅格gap管理间距，避免标签margin重复叠加。SQL/JAR/Catalog优先保留工作区面积，窄屏按内容布局并保持操作可达。
- 覆盖作业、SQL、JAR、Session、模板、镜像、配置密钥、文件、Catalog、用户权限、审计、系统设置、模型服务、登录及编辑/诊断/比较弹窗；旧数据源重定向保持。
- 保留权限、确认、外发授权、3秒按需刷新、同号重试、代码差异高亮、日志滑条和AI等待反馈。
- 桌面、短屏、中等及窄屏验证页面边界、表单和主要操作；示例截图不能冒充真实集群验收。

实现入口及变量见 [UI设计系统](../modules/ui-design-system.md)。
