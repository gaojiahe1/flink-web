# REQ-001 作业生命周期与按需观测

更新：2026-10-20。状态：已实现；本地验证范围见 [验收记录](../validation.md)，不代表真实环境/全部版本验收。

背景：用户需要通过 Operator 管理既有及新建作业，避免常驻 Kubernetes 查询与误删除状态。

需求范围：作业生命周期模块；REQ-001 也覆盖 Operator 查询/诊断/只读 UI。 当前完整细则复用 [功能说明](../../features.md)，配置与环境操作见 [部署指南](../../deployment.md)。

## 验收标准

- 2026-10-20追加：作业管理、JAR、SQL列表使用同一运行状态语义，停止DONE且资源消失显示已停止，失败不显示未部署；发布版本最多5次。

- 进入列表仅查询一次，后续3秒手动刷新；ACCEPTED不当作运行成功。
- 保存点停止要求正常RUNNING及目录；只认本次代数及完成的UPGRADE Savepoint，先持久化路径再按UID/resourceVersion删除。
- 资源消失才可删草稿；纳管只登记，不改spec、不重启；日志和UI需角色/作业权限。

关联：[模块](../modules/job-lifecycle.md)、[ADR](../decisions/ADR-002-safe-stop.md)。关键代码及测试由模块链接定位，不维护第二份路径清单。

重要变更：2026-09-29 编号与名称去重；10-08 Savepoint 确认/恢复；10-09 独立快照查询与日志边界。

来源与确认：功能文档明确用户规则＋当前实现/测试交叉核对；五个可访问旧聊天的近期摘要仅作补充线索。原始全部历史讨论未完整读取。

后续修改更新本记录和相关模块；新验收注明真实环境、版本与未验证范围，不把历史报告当作本轮结果。

- 2026-09-21 用户明确单 namespace、首次进入列表查询一次、多用户/多标签独立刷新、不共享状态缓存；09-28 将手动刷新冷却从 10 秒统一改为 3 秒。Operator 由运维部署，平台不负责安装或修改 Webhook。

## 作业管理聊天的明确要求（2026-10-13 补录）

来源：本次回读 2026-09-29～10-09 的用户正文及非凭据问答，范围见 [本次归档核对](../validation.md#作业与前端修复聊天归档核对2026-10-13)。不把另一聊天的早期来源替换成本聊天来源。

- 09-29/09-30：平台显示名称全局唯一，失焦查重、保存唯一约束兜底；FlinkDeployment 名称只用至少七位的 `flink-0000001` 编号，超过七位不截断、不拼作业名。UUID 用于 API/ACL/文件目录。旧纳管资源先保持原名，停止且确认删除后按编号重建，不能因补编号立即改运行资源。
- 09-30 用户明确确认仅采用“Savepoint 后删除 / 立即删除”；停止最终删除资源而非仅显示 suspended。未确认删除前允许继续停止；保存点失败保留资源，停止关闭确认框后在页面显示进度，不追加结果弹窗。此处 last-state 禁止的是停止策略，不是禁止表单的 last-state 升级策略。
- 09-29～10-01：启动受理后阻止重复启动、立即允许停止；快照执行时后端重查正常运行状态。刷新应更新停止意图和顶部提示；ERROR/status.error 优先显示部署异常。仅进行中的操作显示在单行可横向滚动的提示区，终态在作业行和记录查看。
- 详情移除重复快捷部署/启停/恢复与原始快照块，操作记录与其余详情页签合并；当前 YAML 块状格式、高亮/行号及复制，打开不额外查集群，顶层 status 保留原文。spec/metadata 脱敏边界沿用功能说明，复制不能用于直接重部署。
- 10-08 现场资源紧张，启停与快照测试限定 test2，结束删除该作业和专属上传目录；历史报告已完成，test5-copy 未动。该指令不授权以后测试其他现有作业，也不证明当前环境仍是当时状态。
