# REQ-004 文件、状态存储、平台权限与元数据安全

更新：2026-10-12。状态：已实现；本地验证范围见 [验收记录](../validation.md)，不代表真实环境/全部版本验收。

背景：制品与状态存储需精确边界，登录/配置/元数据需要权限与兼容保护。

需求范围：存储运行文件及元数据权限两个模块；数据源/Catalog登记规则复用功能文档。 当前完整细则复用 [功能说明](../../features.md)，配置与环境操作见 [部署指南](../../deployment.md)。

## 验收标准

- 上传拒绝覆盖；目录删除拒绝桶根/穿越/相邻前缀误删；作业删除只清UUID专属程序/状态目录，停止保留。
- SQLite原数据/迁移/主密钥保留，切换MySQL不自动搬迁；角色+作业ACL，Session+CSRF、敏感字段加密。
- 显式Secret引用兼容；环境值按用户要求展开，预览/历史各脱敏；SDK连通不证明下载器/Flink或厂商认证。
